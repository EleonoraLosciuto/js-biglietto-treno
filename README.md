# JS BIGLIETTO TRENO

A lightweight web application that calculates the price of a train ticket based on distance and passenger age, applying specific discounts for minors and seniors. This was developed as the 11th exercise of the Web Development Master Course.


## TASK

The goal of this exercise was to practice JavaScript logic  - specifically user input (prompt) handling and conditional statements - to automate price calculations based on the following rules:
* Base Price: €0.21 per kilometer.
* Junior Discount (Under 18): 20% off.
* Senior Discount (Over 65): 40% off.
* Standard Fare: Full price for ages 18-65.
